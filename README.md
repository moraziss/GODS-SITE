# GODS-SITE

A small single-page site, "Great Greek Gods", introducing the Olympian gods with portraits (Zeus, Hades, Hermes, Apollo, Ares). Built with plain HTML and Tailwind CSS (loaded from the CDN).

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```

`package.json` and `tailwind.config.js` are present for Tailwind tooling; the page itself needs no build step.

## Structure

- `index.html` - the whole page
- `*.jpg`, `*.webp`, `*.jpeg` - images used by the page
